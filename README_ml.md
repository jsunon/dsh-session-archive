# dsh-session-archive

### സെഷൻ ആർക്കൈവ് — ഒരു DSH സെഷൻ നിർമ്മിക്കുന്ന എല്ലാ ഫയലുകളും വേർതിരിച്ച് സൂക്ഷിക്കുന്നു.

**ഔട്ട്‌പുട്ട് അളവുകോൽ** അനുസരിച്ച് DSH സെഷൻ നിർമ്മിക്കുന്ന ഫയലുകൾ സ്വയമേവ തരംതിരിക്കുന്നു; ഏതാണ് പ്രധാനം, ഏത് ഇല്ലാതാക്കാം, ഏത് സുരക്ഷിതമായി പുറത്തുവിടാം എന്ന് ഒറ്റനോട്ടത്തിൽ അറിയാം.

ഒരു സെഷൻ = ഒരു ഫോൾഡർ. അതിനുള്ളിൽ ആവശ്യാനുസരണം ഡയറക്ടറികൾ സൃഷ്ടിക്കപ്പെടുന്നു (ഡെലിവറബിളുകൾ / സോഴ്സ് / ടൂളുകൾ / ഔട്ട്‌പുട്ട് / റഫറൻസ് / മാലിന്യം). **ശൂന്യമായ ഡയറക്ടറികൾ ഒരിക്കലും സൃഷ്ടിക്കപ്പെടുന്നില്ല**; ഫോൾഡർ റൂട്ടിൽ പരമാവധി 4 ഫയലുകൾ മാത്രം.

- **`code-104-1-2.json` ഇനി വേണ്ട** — കോഡ് ബ്ലോക്കുകൾക്ക് അർത്ഥവത്തായ പേരുകൾ ലഭിക്കുന്നു (`cordis.patch.yml`, `buildName.js`); പേര് ഒന്നുതന്നെയും ഉള്ളടക്കം വ്യത്യസ്തവും → `.vN`
- **ഡ്യൂപ്ലിക്കേറ്റ് പകർപ്പുകളില്ല** — എഴുതുന്നതിന് മുൻപ് sha256 പരിശോധിക്കുന്നു; ഒരേ ഉള്ളടക്കം `_trash/duplicates/` ലേക്ക് പോകുന്നു
- **ഒന്നും കൂടിക്കലരുന്നില്ല** — ഡെലിവറബിളുകൾ, സോഴ്സ്, പുനരുപയോഗിക്കാവുന്ന സ്ക്രിപ്റ്റുകൾ, റഫറൻസ് മെറ്റീരിയൽ, ഒറ്റത്തവണ മാലിന്യം എന്നിവയെല്ലാം അവയുടെ വിഭാഗത്തിൽ തന്നെ നിൽക്കുന്നു
- **തെറ്റായി ഇല്ലാതാക്കിയാലും സുരക്ഷിതം** — `_trash/` ഫോൾഡർ പൂർണമായി ഇല്ലാതാക്കിയാലും യാതൊരു ബാധ്യതയുമില്ല; `01-deliver/` വായനയ്ക്ക് മാത്രമുള്ള കയറ്റുമതിയാണ്, `git push` ചെയ്യേണ്ട ഏക ഫോൾഡറും അതാണ്

ലക്ഷ്യം: DSH Node ഹോസ്റ്റ് പ്രോസസ്സിനുള്ളിൽ പ്രവർത്തിക്കുന്ന DeepSeek Harness (DSH) ഹോസ്റ്റ് പ്ലഗിൻ.

## ഇൻസ്റ്റലേഷൻ

### Release ടാർബോളിൽ നിന്ന് (ശുപാർശ ചെയ്യുന്നു)

```bash
cd ~/.dsh/profiles/<profile-name>
pnpm add https://github.com/jsunon/dsh-session-archive/releases/latest/download/dsh-session-archive.tgz
```

### റെപ്പോസിറ്ററിയിൽ നിന്ന് നേരിട്ട് (ടെസ്റ്റുകളും ഡോക്യുമെന്റേഷനും ഉൾപ്പെടെ)

```bash
pnpm add github:jsunon/dsh-session-archive
```

DSH ഹോസ്റ്റ് റീസ്റ്റാർട്ട് ചെയ്ത് പരിശോധിക്കുക:

```bash
curl http://127.0.0.1:<port>/dsh-session-archive/api/health
```

`dirs`-ൽ ഏഴ് കീകൾ ഉണ്ടെങ്കിൽ (`chat` / `deliver` / `src` / `tools` / `output` / `ref` / `trash`), പുതിയ കോഡ് പ്രവർത്തനക്ഷമമാണ്.

### ലോക്കൽ ഡെവലപ്പ്‌മെന്റ്

ക്ലോൺ ചെയ്ത്, `pnpm add <ലോക്കൽ പാത>` ഉപയോഗിച്ച് ഒരു പ്രൊഫൈൽ അതിലേക്ക് ചൂണ്ടിക്കാണിക്കുക (അല്ലെങ്കിൽ `~/.dsh/local-plugins/`-ൽ നിന്നുള്ള ഒരു ജംഗ്ഷൻ), ഹോസ്റ്റ് റീസ്റ്റാർട്ട് ചെയ്ത്, `node tests/*.test.mjs` ഉപയോഗിച്ച് ആറ് ടെസ്റ്റ് സ്യൂട്ടുകൾ ഓടിക്കുക.

```
<workspace root>/
└─ 【dev-session-archive-plugin】/          ← ഓരോ സെഷനും ഒരു ഫോൾഡർ
   ├─ README.md                             ← സൂചിക: തരം, എന്ത് ഇല്ലാതാക്കാം, പ്രസിദ്ധീകരണത്തിന് മുൻപുള്ള പരിശോധനകൾ
   ├─ MANIFEST.json                         ← ഓഡിറ്റ് ട്രെയിൽ: ഓരോ ഫയലും ഇവിടെ എന്തിന്
   ├─ chat-log.md                           ← പൂർണ ട്രാൻസ്ക്രിപ്റ്റ്
   ├─ session.json                          ← മെറ്റാഡാറ്റ (സെഷൻ ഐഡി, അളവുകൾ, എണ്ണം)
   ├─ 01-deliver/                           ← വായനയ്ക്ക് മാത്രമുള്ള കയറ്റുമതി; git push ചെയ്യേണ്ട ഏക ഫോൾഡർ
   ├─ 02-source/{original,patch,snapshot}/  ← എഴുതാവുന്ന ഏക സത്യസ്രോതസ്സ്; original/ .READONLY ആണ്
   ├─ 03-tools/                             ← പുനരുപയോഗിക്കാവുന്ന സ്ക്രിപ്റ്റുകൾ
   ├─ 04-output/{long-lived,one-off}/       ← കോഡ് അല്ലാത്ത ഔട്ട്‌പുട്ടുകൾ

   └─ _trash/                               ← പൂർണമായി ഇല്ലാതാക്കാം, ബാധ്യതയില്ല
      ├─ duplicates/  unsorted/  failed/  probes/
      ├─ rename-map.json
      ├─ .archive-state.json                ← ഐഡംപൊട്ടൻസി കീകൾ
```

**എന്ത് ഇല്ലാതാക്കാം**: സെഷന്റെ `README.md` തുറക്കുക — "സുരക്ഷിതമായി ഇല്ലാതാക്കാം" എന്ന പട്ടിക അതിൽ ഉണ്ട്; `MANIFEST.json`-ൽ ഓരോ ഫയലിനും `deletable` ഫ്ലാഗ് ഉണ്ട്. **പുറത്തുവിടാമോ**: അതേ `README.md`-ൽ "പ്രസിദ്ധീകരണത്തിന് മുൻപുള്ള പരിശോധനകൾ" എന്ന ഭാഗമുണ്ട്; രഹസ്യങ്ങളോ സ്വകാര്യ കീകളോ കണ്ടെത്തിയാൽ `blocked` എന്ന് അടയാളപ്പെടുത്തുന്നു.

## നിലവിലുള്ള സെഷനുകൾ കൈമാറ്റം ചെയ്യൽ

ആദ്യ ആർക്കൈവിംഗ് പഴയ ഘടന സ്വയം ക്രമീകരിക്കും. ചരിത്രം ഏറെയുണ്ടെങ്കിൽ കൈകൊണ്ട് ഓടിക്കുക — ആദ്യം പ്ലാൻ, പിന്നെ പ്രവർത്തനം:

```bash
# 1) ഡ്രൈ റൺ: അളവുകളും റൂട്ടിംഗ് പ്ലാനും കണക്കാക്കുന്നു, ഒന്നും മാറ്റുന്നില്ല
node bin/plan.mjs "<workspace root>"
# 2) ഒരു സെഷനിൽ പരീക്ഷിക്കുക
node bin/migrate.mjs "<workspace root>" --apply --only "【ഒരു സെഷന്റെ പേര്】"
# 3) പിന്നെ മുഴുവൻ ബാച്ചും
node bin/migrate.mjs "<workspace root>" --apply
```

`--apply`-ന് മുൻപ് ഓരോ ഫയലിന്റെയും ആപേക്ഷിക പാത, വലിപ്പം, sha256 എന്നിവ `_trash/.backup-<timestamp>.json`-ൽ രേഖപ്പെടുത്തുന്നു; ബൈറ്റ് കൃത്യതയിൽ തിരിച്ചുപോകാം. എല്ലാ പ്രവർത്തനങ്ങളും `_trash/.oplog.jsonl`-ൽ രേഖപ്പെടുത്തുന്നു. കൈമാറ്റം **സെഷൻ ഫോൾഡറുകൾക്കുള്ളിൽ മാത്രം പ്രവർത്തിക്കുന്നു, വേൾക്ക്‌സ്പേസ് റൂട്ട് ഒരിക്കലും തൊടുന്നില്ല**.

## കോൺഫിഗറേഷൻ

`cordis.patch.yml`-ലെ `config` തിരുത്തുക, അല്ലെങ്കിൽ സെറ്റിംഗ്‌സ് പാനൽ ഉപയോഗിക്കുക (പാനൽ എഴുതുന്നത് `~/.dsh/storages/session-archive/config.json`-ൽ സ്ഥിരമാകും, അതിനാണ് മുൻഗണന).

പ്രധാന ഓപ്ഷനുകൾ:

| കീ | ഡിഫോൾട്ട് | അർത്ഥം |
| --- | --- | --- |
| `enabled` | `true` | പ്രധാന സ്വിച്ച് |
| `structured` | `true` | തരംതിരിച്ച ഘടന; ഓഫ് ചെയ്താൽ പഴയ പരന്ന ഘടനയിലേക്ക് മടങ്ങും |
| `writeManifest` | `true` | `README.md` + `MANIFEST.json` എഴുതുക |
| `safetyScan` | `true` | പ്രസിദ്ധീകരണത്തിന് മുൻപുള്ള സുരക്ഷാ സ്കാൻ |
| `dedupeByHash` | `true` | sha256 പ്രകാരം ഡ്യൂപ്ലിക്കേറ്റ് ഒഴിവാക്കൽ |
| `strictRoot` | `false` | സെഷൻ റൂട്ടിൽ 4 റൂട്ട് ഫയലുകൾ മാത്രം അനുവദിക്കുക |
| `containerName` | `(ശൂന്യം)` | ശൂന്യമല്ലെങ്കിൽ സെഷൻ ഫോൾഡറുകൾ അതിനടിയിൽ നെസ്റ്റ് ചെയ്യും |
| `dirs.*` | താഴെ കാണുക | ഏഴ് ഡയറക്ടറി പേരുകൾ; ശൂന്യം = ആ വിഭാഗം സൃഷ്ടിക്കില്ല |

```yaml
dirs:
  chat:    chat-log.md
  deliver: 01-deliver
  src:     02-source
  tools:   03-tools
  output:  04-output
  ref:     05-reference
  trash:   _trash
```

എല്ലാ ഓപ്ഷനുകളും: [`docs/config.md`](docs/config.md).

## HTTP API

| രീതി | പാത | ഉദ്ദേശം |
| --- | --- | --- |
| GET | `/dsh-session-archive` | സെറ്റിംഗ്‌സ് പാനൽ (ചൈനീസ് / English / രണ്ടും) |
| GET | `/dsh-session-archive/api/health` | ആരോഗ്യം + നിലവിലെ കോൺഫിഗ് |
| GET | `/dsh-session-archive/api/state` | ആർക്കൈവ് ചെയ്ത സെഷനുകളുടെ പട്ടിക |
| GET | `/dsh-session-archive/api/plan` | **ഡ്രൈ റൺ**: അളവുകളും പ്ലാനും, എഴുത്തില്ല |
| POST | `/dsh-session-archive/api/archive` | ഇപ്പോൾ ആർക്കൈവ് ചെയ്യുക (ഐച്ഛികം `?sessionId=`) |
| POST | `/dsh-session-archive/api/override` | അളവുകൾ ലോക്ക് ചെയ്യുക (`{sessionId, dimensions, locked, lifecycle}`) |
| GET/POST | `/dsh-session-archive/api/config` | കോൺഫിഗ് വായിക്കുക/എഴുതുക |
| GET | `/dsh-session-archive/api/selftest` | സ്വയം പരിശോധന (ഒരു താൽക്കാലിക ഡയറക്ടറിയിൽ ഒരിക്കൽ എഴുതുന്നു) |

തരംതിരിക്കൽ തെറ്റാണോ? കോഡ് മാറ്റരുത് — `POST /api/override` ഉപയോഗിച്ച് ലോക്ക് ചെയ്യുക.

## അൺഇൻസ്റ്റോൾ

നാല് സ്ഥലങ്ങൾ, ക്രമത്തിൽ:

```bash
# 1) സോഴ്സ് പകർപ്പ് നീക്കം ചെയ്യുക (റെപ്പോസിറ്ററിയിൽ നിന്ന് ഇൻസ്റ്റോൾ ചെയ്തെങ്കിൽ ഒഴിവാക്കുക; node_modules-ൽ നിന്ന് മാത്രം നീക്കിയാൽ മതി)
rm -rf ~/.dsh/local-plugins/dsh-session-archive
# 2) പ്രൊഫൈലിലെ ഇൻസ്റ്റോൾ നീക്കം ചെയ്യുക
cd ~/.dsh/profiles/<profile-name>
pnpm remove dsh-session-archive
# 3) റൺടൈം ഇൻഡക്സ് നീക്കം ചെയ്യുക (ഐച്ഛികം; അടുത്ത ആർക്കൈവിംഗിൽ ചരിത്ര ഇൻഡക്സ് പുനർനിർമ്മിക്കപ്പെടും)
rm -rf ~/.dsh/storages/session-archive
```

4. `~/.dsh/profiles/<profile-name>/package.json` പരിശോധിക്കുക: `dependencies`-ലും `dsh.profile.bundles`-ലും `dsh-session-archive` അവശേഷിക്കരുത്.

ഇതിനകം ആർക്കൈവ് ചെയ്ത സെഷൻ ഫോൾഡറുകൾ (`01-deliver/` തുടങ്ങിയവ) **ഇല്ലാതാക്കരുത്**; `_trash/.backup-*.json` ഫയലുകളും **ഇല്ലാതാക്കരുത്** — അവയാണ് നിങ്ങളുടെ തിരിച്ചുപോക്കിന്റെ തെളിവ്.
